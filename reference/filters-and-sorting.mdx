The `search_schools` tool accepts a rich set of parameters that let you narrow results to exactly the institutions you care about. You can combine filters for ownership type, location, price, selectivity, and enrollment size — and then control how results are ordered and paginated. Understanding how these parameters interact helps you build precise, efficient queries that return meaningful results on the first call.

## Filters

Use the following parameters to restrict which schools appear in your `search_schools` results. All filters are optional and composable — you can pass any combination together.

### Location

<ParamField query="state" type="string">
  Restrict results to schools in a specific U.S. state or territory. Pass the standard two-letter postal abbreviation.

  ```text
  Accepted values: "AL", "AK", "AZ", "AR", "CA", "CO", "CT", "DE", "FL", "GA",
                   "HI", "ID", "IL", "IN", "IA", "KS", "KY", "LA", "ME", "MD",
                   "MA", "MI", "MN", "MS", "MO", "MT", "NE", "NV", "NH", "NJ",
                   "NM", "NY", "NC", "ND", "OH", "OK", "OR", "PA", "RI", "SC",
                   "SD", "TN", "TX", "UT", "VT", "VA", "WA", "WV", "WI", "WY",
                   "DC", "PR", "VI", "GU", "AS", "MP"
  ```
</ParamField>

<ParamField query="locale" type="string">
  Filter schools by the geographic setting of their campus. Useful for students who prefer an urban, suburban, or rural environment.

  | Value | Description |
  |---|---|
  | `"city"` | Campus located in a large, midsize, or small city |
  | `"suburb"` | Campus located in a suburban area |
  | `"town"` | Campus located in a town setting |
  | `"rural"` | Campus located in a rural area |
</ParamField>

### Institution Type

<ParamField query="ownership" type="string">
  Filter by the institution's control type. Choose from public, private nonprofit, or private for-profit schools.

  | Value | Description |
  |---|---|
  | `"public"` | State or locally operated institution |
  | `"private_nonprofit"` | Independently operated, tax-exempt institution |
  | `"private_for_profit"` | Privately owned, profit-generating institution |
</ParamField>

### Cost

<ParamField query="min_net_price" type="integer">
  Return only schools whose average net price (after aid) is **at or above** this value, in U.S. dollars. Useful for excluding schools that may have limited financial aid availability for your situation.

  ```text
  Example: 5000 → excludes schools with avg net price below $5,000/yr
  ```
</ParamField>

<ParamField query="max_net_price" type="integer">
  Return only schools whose average net price (after aid) is **at or below** this value, in U.S. dollars. This is one of the most commonly used filters for affordability-focused searches.

  ```text
  Example: 20000 → only schools with avg net price ≤ $20,000/yr
  ```
</ParamField>

### Selectivity & Outcomes

<ParamField query="max_admission_rate" type="number">
  Return only schools whose overall admission rate is **at or below** this value. Pass a decimal between `0.0` and `1.0`. Use this to find highly selective institutions.

  ```text
  Example: 0.10 → only schools admitting 10% or fewer applicants
  Example: 0.50 → only schools admitting fewer than half of applicants
  ```
</ParamField>

<ParamField query="min_graduation_rate" type="number">
  Return only schools whose 4-year graduation rate (at 150% normal time) is **at or above** this value. Pass a decimal between `0.0` and `1.0`.

  ```text
  Example: 0.80 → only schools where 80%+ of students graduate on time
  ```
</ParamField>

### Enrollment Size

<ParamField query="min_student_size" type="integer">
  Return only schools with a total undergraduate enrollment **at or above** this number. Use this to find large research universities or institutions with broad program offerings.

  ```text
  Example: 10000 → only schools with 10,000+ undergraduates
  ```
</ParamField>

<ParamField query="max_student_size" type="integer">
  Return only schools with a total undergraduate enrollment **at or below** this number. Use this to find small colleges with lower student-to-faculty ratios.

  ```text
  Example: 2500 → only schools with 2,500 or fewer undergraduates
  ```
</ParamField>

<Tip>
  Combine multiple filters to dramatically narrow large result sets. For example, pairing `state: "CA"`, `max_net_price: 15000`, and `min_graduation_rate: 0.70` targets affordable, high-outcome California schools in a single call — without needing to manually sift through hundreds of results.
</Tip>

## Sorting

Control the order in which matching schools appear using the `sort_by` and `sort_order` parameters.

<ParamField query="sort_by" type="string" default="name">
  The field to use as the sort key. Choose from the following options:

  | Value | Sorts by |
  |---|---|
  | `"name"` | School name (alphabetical) |
  | `"admission_rate"` | Overall admission rate |
  | `"graduation_rate_4yr"` | 4-year graduation rate |
  | `"avg_net_price"` | Average net price after aid |
  | `"median_earnings_10yr"` | Median earnings 10 years after entry |
  | `"student_size"` | Total undergraduate enrollment |
</ParamField>

<ParamField query="sort_order" type="string" default="asc">
  The direction of the sort. Pass `"asc"` for ascending order (lowest first, A→Z) or `"desc"` for descending order (highest first, Z→A).

  | Value | Effect |
  |---|---|
  | `"asc"` | Lowest values first (e.g., most affordable, least selective) |
  | `"desc"` | Highest values first (e.g., top earners, highest graduation rates) |
</ParamField>

## Pagination

The `search_schools` tool paginates results so that large result sets remain manageable. Use these parameters to step through pages of results.

<ParamField query="page" type="integer" default="0">
  The zero-indexed page number to return. The first page is `0`, the second is `1`, and so on.
</ParamField>

<ParamField query="per_page" type="integer" default="10">
  The number of results to return per page. The minimum value is `1` and the maximum is `100`.

  <Warning>
    Requesting more than 100 results per page is not supported. If you need to retrieve a large number of schools, iterate through pages using the `page` parameter.
  </Warning>
</ParamField>

## Full Example

The following example demonstrates a `search_schools` call that combines multiple filters, a custom sort, and explicit pagination. It searches for mid-sized public universities in Texas with strong graduation rates and affordable net prices, sorted by median earnings.

<CodeGroup>

```json MCP Tool Call
{
  "tool": "search_schools",
  "parameters": {
    "state": "TX",
    "ownership": "public",
    "min_student_size": 5000,
    "max_student_size": 30000,
    "min_graduation_rate": 0.60,
    "max_net_price": 18000,
    "sort_by": "median_earnings_10yr",
    "sort_order": "desc",
    "page": 0,
    "per_page": 10
  }
}
```

```json Example Response (truncated)
{
  "total": 14,
  "page": 0,
  "per_page": 10,
  "results": [
    {
      "id": 228723,
      "name": "The University of Texas at Dallas",
      "city": "Richardson",
      "state": "TX",
      "ownership": "Public",
      "student_size": 22102,
      "avg_net_price": 12450,
      "graduation_rate_4yr": 0.71,
      "median_earnings_10yr": 68400
    },
    {
      "id": 228769,
      "name": "Texas A&M University-Commerce",
      "city": "Commerce",
      "state": "TX",
      "ownership": "Public",
      "student_size": 10871,
      "avg_net_price": 11200,
      "graduation_rate_4yr": 0.62,
      "median_earnings_10yr": 52100
    }
  ]
}
```

</CodeGroup>

<Note>
  The `total` field in the response reflects the total number of matching schools across all pages — not just the current page. Use it to calculate how many additional pages exist: `total_pages = ceil(total / per_page)`.
</Note>
