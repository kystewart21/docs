OpenTweet connects AI agents, developers, and creators to X (Twitter) through a hosted MCP server, a REST API, and a CLI. You get one `ot_` API key from the dashboard, point any MCP client at `https://mcp.opentweet.io/mcp`, and your first post goes out in under three minutes — no X developer account, no OAuth plumbing, no per-post billing.

## How It Works

<Steps>
  <Step title="Create an API key">
    Sign in at [opentweet.io/dashboard](https://opentweet.io/dashboard), go to the **Developer** section, and generate an `ot_` key. Connect your X account in the same step — no X developer account required.
  </Step>
  <Step title="Choose your integration">
    Use the hosted MCP server for AI agents (Claude, Cursor, ChatGPT), the REST API for backend code, or the CLI for terminal and CI/CD pipelines. All three use the same key.
  </Step>
  <Step title="Post, schedule, or automate">
    Publish immediately, schedule at a future date, or let your agent fill the queue. Every post lands on the same visual calendar — editable by you or your agent until it goes live.
  </Step>
  <Step title="Review and analyze">
    Open the calendar to review agent-created drafts before they ship. Use analytics to track impressions, engagement, and the best times to post.
  </Step>
</Steps>
