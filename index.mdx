The College Scorecard MCP server bridges the U.S. Department of Education's College Scorecard dataset and any MCP-compatible AI assistant. With a single HTTPS endpoint, your AI agent gains structured tools for searching schools, retrieving detailed institutional data, comparing colleges side-by-side, and exploring academic programs — all without managing API keys or raw HTTP requests.

## What You Can Do

The College Scorecard MCP exposes four tools your AI agent can call directly:

<CardGroup cols={2}>
  <Card title="search_schools" icon="magnifying-glass" href="/tools/search-schools">
    Find institutions by name, location, type, or any scorecard attribute
  </Card>
  <Card title="get_school" icon="school" href="/tools/get-school">
    Retrieve the full scorecard profile for a single institution
  </Card>
  <Card title="compare_schools" icon="chart-bar" href="/tools/compare-schools">

## How It Works

<Steps>
  <Step title="Connect your AI assistant">
    Point your MCP-compatible client (Claude, Cursor, or any MCP-enabled tool) to `https://your-service.example.com/mcp`.
  </Step>
  <Step title="Discover available tools">
    The server automatically advertises its tool list. Your assistant sees `search_schools`, `get_school`, `compare_schools`, and `find_programs`.
  </Step>
  <Step title="Ask questions in natural language">
    Your assistant translates user queries into tool calls — no manual API integration required.
  </Step>
  <Step title="Get structured data back">
    Each tool returns clean, structured JSON sourced directly from the official College Scorecard dataset.
  </Step>
</Steps>

<Note>
  The College Scorecard MCP server manages all API authentication server-side. You do not need to obtain or configure a College Scorecard API key to use this service.
</Note>
