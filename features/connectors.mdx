Connectors are automated content pipelines that watch an external source and generate a post whenever something new appears. Point a connector at your blog, GitHub repo, Stripe account, or any webhook-enabled service, and OpenTweet handles the rest — no code required on your side.

Set up any connector from **Dashboard → Connectors → New**.

## Available Connectors

### RSS Connector

Connect any RSS feed — WordPress, Substack, Ghost, or any RSS-enabled blog — and OpenTweet automatically drafts an engaging tweet when a new post is detected. OpenTweet checks for new items within minutes of publication, then uses AI to turn the post title and content into a tweet that fits your voice.

**Setup:** Dashboard → Connectors → New → RSS → paste your feed URL → Save.

---

### GitHub Connector

Link a GitHub repository and OpenTweet posts on your behalf when you push a new commit, cut a release, or publish a tag. It's the easiest way to keep your audience updated on shipping cadence — for example: *"v2.4.0 is out. Changelog in thread."*

**Setup:** Dashboard → Connectors → New → GitHub → authorize with GitHub → select your repository.

---

### Stripe Connector

Celebrate revenue milestones automatically. When a new customer signs up, your MRR crosses a threshold, or another Stripe event fires, OpenTweet drafts a post with context so you never miss a moment worth sharing.

**Setup:** Dashboard → Connectors → New → Stripe → paste your Stripe webhook secret → Save.

---

### API / Webhook Connector

Point any JSON webhook at your OpenTweet endpoint and the connector drafts a post from the payload. Use this for custom integrations like deployment pipelines, monitoring alerts, CI/CD events, or anything else that can fire a webhook.

**Setup:** Dashboard → Connectors → New → Webhook → copy your unique webhook URL → configure your source to POST to it.

---

### SaaS Connector

Purpose-built for SaaS products, this connector turns key product events — new signups, plan upgrades, churn notifications — into tweets with relevant context automatically. Connect it to your product's event stream and your account stays active with real milestones.

**Setup:** Dashboard → Connectors → New → SaaS → follow the guided setup for your event source.

---

## Reviewing Connector-Generated Posts

All posts generated by a connector appear in your **calendar queue** as drafts before publishing. You can review, edit, or delete any draft before it goes live. If you trust a connector's output, enable **Auto-Approve** per connector in its settings to publish without the review step.

<Note>
  Posts generated by connectors count toward your plan's daily post limit, whether you review them manually or publish them via auto-approve.
</Note>
