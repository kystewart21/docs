Verify BOX College Scorecard with a real tool response before using it for academic or financial recommendations. Merely seeing four tools in a menu does not prove the connection works.

<Steps>

  <Step title="Use the authorised account">
    Open the existing BOX College Scorecard plugin in the intended workspace. Use its normal connection flow and approve only the expected access.
  </Step>

  <Step title="Verify Sites permission">
    For Playincollege.ai, check the consuming Site's plugin eligibility. Continue only when the exact BOX Scorecard plugin is allowed. Keep visitor consent and the site's existing audience intact.
  </Step>

  <Step title="Retrieve one institution">
    Invoke `get_school` with a confirmed federal UNITID. The following is an example tool input, not a verified response:

    ```json
    {"id": 110404}
    ```

    Check the returned name, state and ID against the intended institution. Preserve the source and retrieval timestamp.
  </Step>

  <Step title="Verify the assessment path">
    Ask the hosted recruiting AI a bounded cost or admissions question about that institution. Confirm the answer uses the actual returned facts and persists after reload. Missing reporting years must remain unknown.
  </Step>

</Steps>

Use `find_programs` to check the requested CIP and credential level. An institution-level result does not verify every engineering specialism. Use `compare_schools` only with resolved institution IDs.

If a step fails, retain a research hold for the affected claims. Do not fabricate a successful result or substitute OpenTweet endpoints. See [Authentication](/authentication) and [Endpoint reference](/api/overview).
