This guide walks you through getting an API key, connecting your X account, and sending your first post — all in under three minutes. Pick the integration path that fits your workflow: REST API, MCP server for AI agents, or the CLI.

<Steps>

<Step title="Get an API Key">

Sign in at [https://opentweet.io/auth/login](https://opentweet.io/auth/login) to start your free 7-day trial (no credit card required). Once you're in the dashboard, navigate to the **Developer** section and click **New API Key**.

Your key is displayed **only once** at creation time — copy it immediately and store it somewhere safe (a password manager or secrets vault works well).

<Warning>
Never put your `ot_` key in client-side code, a public repository, or anywhere else that could be read by a third party. Anyone who holds your key can post to your connected X account.
</Warning>

</Step>

<Step title="Connect Your X Account">

From the dashboard, click **Connect X Account** and complete the authorization flow. OpenTweet handles all X API credentials on your behalf — you do not need an X developer account or an API key from X.

The entire authorization flow takes under two minutes.

</Step>

<Step title="Post to X">

Choose how you want to publish — via the REST API, an MCP-compatible AI agent, or the CLI:

<Tabs>

<Tab title="REST API">

Use `curl` (or any HTTP client) to publish immediately or schedule a post for later:

```bash
# Publish immediately
curl -X POST https://opentweet.io/api/v1/posts \
  -H 'Authorization: Bearer ot_your_key' \
  -H 'Content-Type: application/json' \
  -d '{"text": "Hello from my code.", "publish_now": true}'

# Schedule for later (ISO 8601 date)
curl -X POST https://opentweet.io/api/v1/posts \
  -H 'Authorization: Bearer ot_your_key' \
  -H 'Content-Type: application/json' \
  -d '{"text": "Launch day.", "scheduled_date": "2026-07-10T09:00:00Z"}'
```

A successful response looks like this:

```json
{ "success": true, "posts": [{ "id": "...", "status": "scheduled" }] }
```

</Tab>

<Tab title="MCP Server (AI Agents)">

Paste the following config block into your MCP client — Claude Desktop, Cursor, Windsurf, ChatGPT, or any client that supports the MCP protocol. Replace `ot_your_key` with your actual API key.

```json claude_desktop_config.json
{
  "mcpServers": {
    "opentweet": {
      "type": "streamable-http",
      "url": "https://mcp.opentweet.io/mcp",
      "headers": { "Authorization": "Bearer ot_your_key" }
    }
  }
}
```

Restart the client after saving the config. Your agent now has access to **43 tools** for posting, scheduling, analytics, and more. Try prompting it:

> "Post a tweet that says hello from MCP."

</Tab>

<Tab title="CLI">

Install the OpenTweet CLI globally, authenticate with your `ot_` key, then post or schedule in a single command:

```bash
npm install -g @opentweet/cli
opentweet auth              # paste your ot_ key when prompted
opentweet tweet 'Shipped a new release.' --now
opentweet tweet 'Big launch.' --schedule '2026-07-10 09:00'
```

</Tab>

</Tabs>

</Step>

</Steps>
