The College Scorecard MCP makes it straightforward to move from an open-ended question — "which engineering schools in Texas give students the best financial outcomes?" — to a structured, side-by-side comparison in just a few tool calls. This guide walks you through the complete workflow: finding candidate schools, narrowing the list, running the comparison, and reading the results intelligently.

## Step-by-Step Comparison Workflow

<Steps>
  <Step title="Search for schools of interest">
    Start with `search_schools` to discover institutions that match your initial criteria. Pass a descriptive `query` string and use `filters` to narrow by geography, ownership type, size, or any College Scorecard field.

    The following example finds public universities in Texas that offer engineering programs and have at least 5,000 students.

    ```json Request
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "tools/call",
      "params": {
        "name": "search_schools",
        "arguments": {
          "query": "engineering",
          "filters": {
            "state": "TX",
            "ownership": 1,
            "min_size": 5000
          },
          "fields": [
            "id",
            "school.name",
            "school.city",
            "latest.student.size",
            "latest.admissions.admission_rate.overall",
            "latest.cost.avg_net_price.overall"
          ],
          "per_page": 10
        }
      }
    }
    ```

    ```json Response
    {
      "jsonrpc": "2.0",
      "id": 1,
      "result": {
        "content": [
          {
            "type": "text",
            "text": "{\"total\": 18, \"results\": [{\"id\": 228723, \"school.name\": \"University of Texas at Austin\", \"school.city\": \"Austin\", \"latest.student.size\": 50476, \"latest.admissions.admission_rate.overall\": 0.317, \"latest.cost.avg_net_price.overall\": 15320}, {\"id\": 228459, \"school.name\": \"Texas A&M University\", \"school.city\": \"College Station\", \"latest.student.size\": 72982, \"latest.admissions.admission_rate.overall\": 0.631, \"latest.cost.avg_net_price.overall\": 13875}, {\"id\": 225511, \"school.name\": \"University of Houston\", \"school.city\": \"Houston\", \"latest.student.size\": 46432, \"latest.admissions.admission_rate.overall\": 0.647, \"latest.cost.avg_net_price.overall\": 12140}]}"
          }
        ]
      }
    }
    ```

    Each result includes the school's numeric `id` — hold onto those IDs because you will need them in the next step.
  </Step>

  <Step title="Pick school IDs from the results">
    Review the results and select the schools you want to compare. You are not limited to the top result — scroll through the full list and pick any combination of IDs that represents a meaningful comparison set.

    From the example above, the three school IDs are:

    | School | ID |
    |--------|----|
    | University of Texas at Austin | `228723` |
    | Texas A&M University | `228459` |
    | University of Houston | `225511` |

    <Tip>
      Use the `fields` parameter in your `search_schools` call to surface the metrics most relevant to your priorities upfront. If cost is the primary concern, include `latest.cost.avg_net_price.overall` and `latest.cost.tuition.in_state` in the initial search so you can pre-filter before running the full comparison. If career outcomes matter most, pull `latest.earnings.10_yrs_after_entry.median` instead.
    </Tip>
  </Step>

  <Step title="Call compare_schools with those IDs">
    Pass the selected IDs to `compare_schools`. Use the `fields` parameter to specify exactly which metrics you want to see side by side.

    ```json Request
    {
      "jsonrpc": "2.0",
      "id": 2,
      "method": "tools/call",
      "params": {
        "name": "compare_schools",
        "arguments": {
          "school_ids": [228723, 228459, 225511],
          "fields": [
            "school.name",
            "school.city",
            "latest.student.size",
            "latest.admissions.admission_rate.overall",
            "latest.completion.completion_rate_4yr_150nt",
            "latest.earnings.10_yrs_after_entry.median",
            "latest.cost.avg_net_price.overall",
            "latest.cost.tuition.in_state",
            "latest.cost.tuition.out_of_state"
          ]
        }
      }
    }
    ```

    ```json Response
    {
      "jsonrpc": "2.0",
      "id": 2,
      "result": {
        "content": [
          {
            "type": "text",
            "text": "{\"comparison\": [{\"id\": 228723, \"school.name\": \"University of Texas at Austin\", \"school.city\": \"Austin\", \"latest.student.size\": 50476, \"latest.admissions.admission_rate.overall\": 0.317, \"latest.completion.completion_rate_4yr_150nt\": 0.698, \"latest.earnings.10_yrs_after_entry.median\": 62400, \"latest.cost.avg_net_price.overall\": 15320, \"latest.cost.tuition.in_state\": 11448, \"latest.cost.tuition.out_of_state\": 38228}, {\"id\": 228459, \"school.name\": \"Texas A&M University\", \"school.city\": \"College Station\", \"latest.student.size\": 72982, \"latest.admissions.admission_rate.overall\": 0.631, \"latest.completion.completion_rate_4yr_150nt\": 0.652, \"latest.earnings.10_yrs_after_entry.median\": 58700, \"latest.cost.avg_net_price.overall\": 13875, \"latest.cost.tuition.in_state\": 10294, \"latest.cost.tuition.out_of_state\": 37294}, {\"id\": 225511, \"school.name\": \"University of Houston\", \"school.city\": \"Houston\", \"latest.student.size\": 46432, \"latest.admissions.admission_rate.overall\": 0.647, \"latest.completion.completion_rate_4yr_150nt\": 0.471, \"latest.earnings.10_yrs_after_entry.median\": 53200, \"latest.cost.avg_net_price.overall\": 12140, \"latest.cost.tuition.in_state\": 9006, \"latest.cost.tuition.out_of_state\": 21006}]}"
          }
        ]
      }
    }
    ```
  </Step>

  <Step title="Interpret the comparison results">
    The comparison returns one object per school with the same field keys, making it easy to scan across rows. Here is what each metric represents in plain language.

    #### avg_net_price (`latest.cost.avg_net_price.overall`)
    The average amount students actually pay after grants and scholarships are applied — not the sticker price. This figure is calculated across all students who received federal financial aid. A lower net price means students are receiving more aid on average, but remember that your individual aid package depends on your household income and academic profile.

    #### admission_rate (`latest.admissions.admission_rate.overall`)
    The percentage of applicants who were offered admission. A value of `0.317` means 31.7% of applicants were admitted. A lower rate indicates a more selective institution, but selectivity alone is not a measure of quality or fit.

    #### median_earnings_10yr (`latest.earnings.10_yrs_after_entry.median`)
    The median annual earnings of students who enrolled (not necessarily graduated) at the institution, measured 10 years after they first enrolled. This is one of the most powerful outcome metrics in College Scorecard data because it captures real-world earnings across all graduates of the institution, not just a specific program.

    #### graduation_rate_4yr (`latest.completion.completion_rate_4yr_150nt`)
    The percentage of first-time, full-time bachelor's degree-seeking students who completed their degree within 150% of the expected time (6 years for a 4-year program). Higher rates suggest stronger academic support, financial stability, and student satisfaction.

    <Info>
      All College Scorecard metrics are lagged by 1–3 years due to the data collection cycle. Earnings data in particular reflects graduates from several cohorts ago, so treat them as directional indicators rather than precise current-year figures.
    </Info>
  </Step>

  <Step title="Drill into a specific school with get_school">
    Once you have identified a frontrunner, use `get_school` to retrieve its complete data profile. Unlike `compare_schools`, `get_school` returns every available field for a single institution — useful for deep research on a finalist.

    ```json Request
    {
      "jsonrpc": "2.0",
      "id": 3,
      "method": "tools/call",
      "params": {
        "name": "get_school",
        "arguments": {
          "school_id": 228723,
          "fields": [
            "school.name",
            "school.alias",
            "school.city",
            "school.state",
            "school.school_url",
            "school.ownership",
            "school.locale",
            "latest.student.size",
            "latest.admissions.admission_rate.overall",
            "latest.admissions.sat_scores.average.overall",
            "latest.admissions.act_scores.midpoint.cumulative",
            "latest.completion.completion_rate_4yr_150nt",
            "latest.earnings.10_yrs_after_entry.median",
            "latest.cost.avg_net_price.overall",
            "latest.cost.tuition.in_state",
            "latest.cost.tuition.out_of_state",
            "latest.aid.median_debt.completers.overall",
            "latest.programs.cip_4_digit"
          ]
        }
      }
    }
    ```

    ```json Response
    {
      "jsonrpc": "2.0",
      "id": 3,
      "result": {
        "content": [
          {
            "type": "text",
            "text": "{\"id\": 228723, \"school.name\": \"University of Texas at Austin\", \"school.alias\": \"UT Austin\", \"school.city\": \"Austin\", \"school.state\": \"TX\", \"school.school_url\": \"www.utexas.edu\", \"school.ownership\": 1, \"school.locale\": 11, \"latest.student.size\": 50476, \"latest.admissions.admission_rate.overall\": 0.317, \"latest.admissions.sat_scores.average.overall\": 1340, \"latest.admissions.act_scores.midpoint.cumulative\": 31, \"latest.completion.completion_rate_4yr_150nt\": 0.698, \"latest.earnings.10_yrs_after_entry.median\": 62400, \"latest.cost.avg_net_price.overall\": 15320, \"latest.cost.tuition.in_state\": 11448, \"latest.cost.tuition.out_of_state\": 38228, \"latest.aid.median_debt.completers.overall\": 18500}"
          }
        ]
      }
    }
    ```
  </Step>
</Steps>

## What the Data Means

Understanding the nuances behind College Scorecard metrics helps you make more accurate recommendations and avoids common misinterpretations.

<CardGroup cols={2}>
  <Card title="Net Price vs. Sticker Price" icon="tag">
    Published tuition (`latest.cost.tuition.in_state`) is the sticker price before any aid. Average net price (`latest.cost.avg_net_price.overall`) reflects what aided students typically pay. For cost comparisons, net price is almost always the more meaningful figure.
  </Card>
  <Card title="Earnings Are Institution-Wide" icon="chart-line">
    The 10-year median earnings figure covers all graduates of the institution, not a specific program. An engineering student at a liberal-arts college will likely out-earn the institution median; a fine-arts student at a technical university may earn less. Use `find_programs` for program-specific earnings where available.
  </Card>
  <Card title="Ownership Codes" icon="building-columns">
    The `school.ownership` field uses numeric codes: `1` = public, `2` = private nonprofit, `3` = private for-profit. Always filter by ownership when comparisons are meant to be apples-to-apples.
  </Card>
  <Card title="Locale Codes" icon="map-pin">
    The `school.locale` field encodes urbanicity: `11` = large city, `12` = midsize city, `13` = urban fringe, `21` = large suburb, `31` = fringe town, `41` = remote rural. Use locale filters when campus environment is a priority for a student.
  </Card>
</CardGroup>

<Warning>
  College Scorecard data for some schools — particularly small private institutions and for-profit colleges — may have suppressed or null values for earnings and completion metrics when the sample size is too small to report reliably. A null field does not mean the school is bad; it means the data is not available. Fall back to `get_school` to see whether other fields are populated for context.
</Warning>
