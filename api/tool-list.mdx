The College Scorecard MCP server publishes a machine-readable manifest that describes every tool it exposes — including each tool's name, description, and full JSON Schema for its input parameters. MCP-compatible clients fetch this manifest automatically during session initialization, so your AI assistant always has an up-to-date picture of what the server can do. You can also retrieve the manifest manually at any time for debugging or integration purposes.

## How to Retrieve the Tool List

<Tabs>
  <Tab title="HTTP GET">
    Send a GET request to the MCP endpoint. This is the simplest way to inspect the manifest from a terminal or browser.

    ```bash
    curl https://box-college-scorecard-mcp.box-athletic-6399.chatgpt.site/api/mcp
    ```
  </Tab>
  <Tab title="JSON-RPC tools/list">
    Send a `tools/list` JSON-RPC call via POST. Use this form when you need the manifest inside a programmatic workflow that already speaks JSON-RPC 2.0.

    ```bash
    curl -X POST https://box-college-scorecard-mcp.box-athletic-6399.chatgpt.site/api/mcp \
      -H "Content-Type: application/json" \
      -d '{
        "jsonrpc": "2.0",
        "method": "tools/list",
        "params": {},
        "id": 1
      }'
    ```
  </Tab>
</Tabs>

<Note>
  MCP-compatible clients (Claude Desktop, Cursor, Windsurf, and similar) call
  `tools/list` automatically as part of their session handshake. You do not need
  to fetch the manifest yourself when using a supported client.
</Note>

## Input Schema Notes

<Accordion title="Required vs. optional parameters">
  Parameters listed under `required` in a tool's `inputSchema` must be present in every call. All other parameters are optional. When an optional parameter is omitted, the server applies the default value specified in the schema (e.g., `page` defaults to `0`, `per_page` defaults to `10`).
</Accordion>

<Accordion title="Enum validation">
  Fields with an `enum` constraint (such as `ownership`, `locale`, `sort_by`, and `sort_order`) only accept the exact string values listed. Passing an unlisted value results in a `-32602 Invalid Params` error. Values are case-sensitive.
</Accordion>

<Accordion title="Pagination parameters">
  Both `search_schools` and `find_programs` support `page` (zero-indexed) and `per_page` (maximum 100). To retrieve the second page of 20 results, pass `"page": 1, "per_page": 20`. The total number of matching records is returned in the `total` field of the response so you can calculate how many pages exist.
</Accordion>
