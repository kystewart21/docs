The OpenTweet REST API gives you programmatic control over every feature in the platform — post creation, scheduling, media uploads, analytics, and account management. Every paid plan (Pro, Advanced, and Agency) includes full API access with no add-on required.

## Base URL

All API requests go to:

```
https://opentweet.io
```

Every endpoint returns JSON. Send `Content-Type: application/json` on all `POST` and `PUT` requests.

## Authentication

Authenticate every request by passing your `ot_` API key in one of two headers:

```bash
# Option 1 — Authorization header (preferred)
Authorization: Bearer ot_your_key

# Option 2 — X-API-Key header
X-API-Key: ot_your_key
```

See the [Authentication guide](/api/authentication) for full details on creating, rotating, and revoking keys.

## Quick Start

```bash
# Verify your key
curl -H 'Authorization: Bearer ot_your_key' https://opentweet.io/api/v1/me

# Post immediately
curl -X POST https://opentweet.io/api/v1/posts \
  -H 'Authorization: Bearer ot_your_key' \
  -H 'Content-Type: application/json' \
  -d '{"text": "Hello from the API!", "publish_now": true}'
```

Ready to dive in? Follow the [Quickstart guide](/quickstart) for a step-by-step walkthrough, or explore the full endpoint reference below.

### Account

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/me` | Verify key, check subscription and limits |
| `GET` | `/api/v1/accounts` | List connected X accounts |
| `GET` | `/api/v1/cross-posting` | Cross-posting targets and per-network limits |

### Posts

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/posts` | List posts with pagination and status filter |
| `POST` | `/api/v1/posts` | Create, schedule, or bulk-create posts |
| `GET` | `/api/v1/posts/:id` | Get a single post |
| `PUT` | `/api/v1/posts/:id` | Update a draft or scheduled post |
| `DELETE` | `/api/v1/posts/:id` | Delete a post |
| `POST` | `/api/v1/posts/:id/schedule` | Schedule a post |
| `POST` | `/api/v1/posts/:id/publish` | Publish a post immediately |
| `POST` | `/api/v1/posts/batch-schedule` | Schedule up to 50 posts at once |

### Articles

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/articles` | List articles |
| `POST` | `/api/v1/articles` | Create an article |
| `PUT` | `/api/v1/articles/:id` | Update an article |
| `POST` | `/api/v1/articles/:id/publish` | Publish an article immediately |

### Media

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/v1/upload` | Upload media (image or video) |

### Analytics

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/analytics/overview` | Account-level analytics |
| `GET` | `/api/v1/analytics/tweets` | Tweet engagement metrics (Advanced+) |
| `GET` | `/api/v1/analytics/best-times` | Best posting times |

<Note>
  Tweet engagement analytics (`/api/v1/analytics/tweets`) require an **Advanced** plan or higher. Calling this endpoint on a Pro plan returns a `403` response.
</Note>

## Plan Access

The API is available on every paid OpenTweet plan. Rate limits and daily post caps vary by plan — see the [Rate Limits reference](/api/rate-limits) for the full breakdown.

| Plan | API Access | Requests/min | Posts/day |
|------|------------|--------------|-----------|
| Pro | ✓ | 60 | 20 |
| Advanced | ✓ | 300 | 100 |
| Agency | ✓ | 300 | 300 |
