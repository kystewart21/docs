BOX College Scorecard exposes institution and programme lookup tools. Use the transport and authentication details returned by the Site's supported MCP connection rather than copying a generic client's configuration.

## Service identity

| Item | Value |
| --- | --- |
| Service origin | `https://box-college-scorecard-mcp.box-athletic-6399.chatgpt.site` |
| Legacy registered route | `/api/mcp` |
| Provisioned Sites MCP route | `/mcp`, confirmed in version 3 |
| Data provider | U.S. Department of Education College Scorecard |
| Purpose | Read-only college research |

The service's MCP route and the [official upstream API documentation](https://collegescorecard.ed.gov/data/documentation/) are separate interfaces. Mintlify hosts this documentation; it does not implement the BOX data service.

## Tool inputs

| Tool | Required input | Optional input |
| --- | --- | --- |
| `search_schools` | None | `query`, `filters`, `page`, `per_page`, `sort_by`, `sort_order` |
| `get_school` | Integer `id` (UNITID) | None |
| `compare_schools` | `ids`, two to five UNITIDs | `fields` |
| `find_programs` | `cip_code` | `school_id`, `credential_level`, `page`, `per_page` |

Use the discovered tool schema for current accepted filters and bounds. Do not infer support for an arbitrary Scorecard field from these examples.

## Example tool call

This JSON-RPC body illustrates a lookup. It is not an anonymous curl recipe or a captured successful result.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_school",
    "arguments": {"id": 110404}
  }
}
```

## Evidence handling

A successful MCP transport response alone is insufficient. Check for a tool error, verify institution identity and retain source metadata. Do not invent a response schema, reporting year or financial-aid award. Distinguish the date data was retrieved from the period measured.

See [Authentication](/authentication) for the separate 401 and workspace 403 cases. No Scorecard request should be directed to an OpenTweet URL.
