BOX College Scorecard exposes four lookup tools. Their inputs are school-search constraints, federal institution IDs and CIP programme codes, not private athlete records.

| Tool | Use |
| --- | --- |
| [search_schools](/tools/search-schools) | Discover institution IDs with supported filters |
| [get_school](/tools/get-school) | Retrieve one institution by UNITID |
| [compare_schools](/tools/compare-schools) | Compare two to five institutions |
| [find_programs](/tools/find-programs) | Query reported programmes by CIP |

Use the current discovered input schema as the authority for parameters. The worker labels the source and retrieval time; it does not supply a reporting year for every measure.

A successful lookup is academic and financial evidence, not an admissions decision, aid offer or baseball roster assessment. See [Authentication](/authentication) before attempting a call.
