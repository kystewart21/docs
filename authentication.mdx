BOX College Scorecard is currently workspace restricted. Public government data does not make the hosted service anonymously accessible. Use the supported Sites-provisioned plugin connection.

## Three separate permissions

1. The signed-in account must be authorised to access the Scorecard Site
2. The workspace must allow the consuming Site to use the Scorecard plugin
3. The visitor must approve the connection where required

Sharing the MCP with a second account does not automatically grant the recruiting website access through that account. A normal browser session is not a background service credential.

## Credentials

Do not paste API keys, session cookies or access tokens into this documentation, URLs or chat. The upstream Department of Education credential belongs in the service's server-side secret store. It is separate from visitor authentication.

Do not send a College Scorecard key to OpenTweet. OpenTweet endpoints and `ot_` credentials are unrelated to this service.

## Diagnose access failures

| Observation | Meaning and action |
| --- | --- |
| HTTP 401 with a ChatGPT sign-in page | The request has not reached a successfully authenticated tool execution. Reconnect through the supported plugin flow |
| HTTP 403 with `sites_workspace_app_access_denied` | Sites reports a workspace delegation restriction. Reconcile effective policy; changing an upstream API key does not resolve it |
| Sites reports no declared MCP server | Check the service's MCP capability declaration and supported route, then republish through Sites |
| Tool-level error | Inspect the returned error without labelling missing data as zero or claiming verification |

The endpoint is not documented as anonymous. Do not make it public or disable sign-in merely to clear an error. See [Quickstart](/quickstart) for the verification sequence.
