BOX College Scorecard provides read-only institutional and programme research for B.O.X. recruiting assessments. This documentation describes the BOX service, not OpenTweet or X posting.

## Data and limits

The four tools retrieve U.S. Department of Education College Scorecard data. Retain the returned institution identity, source and retrieval date. A retrieval date is not the underlying reporting year. Missing or suppressed values remain unknown.

| Tool | Purpose |
| --- | --- |
| `search_schools` | Search institutions by name and supported filters |
| `get_school` | Retrieve an institution by federal UNITID |
| `compare_schools` | Compare two to five institutions |
| `find_programs` | Research reported fields of study using CIP codes |

Scorecard does not establish NCAA division, baseball sponsorship, roster openings, coach interest, individual admission probability or a family's financial-aid offer. Verify those separately.

## Connection

Use the Site-provisioned BOX College Scorecard plugin and its supported authenticated connection. A browser login, shared document or Mintlify account does not authorise a server-to-server request.

See [Authentication](/authentication), [Quickstart](/quickstart) and [Endpoint reference](/api/overview). The registered legacy endpoint is `https://box-college-scorecard-mcp.box-athletic-6399.chatgpt.site/api/mcp`. The supported Sites MCP route is `/mcp`; use the connection URL returned by Sites after publication.
