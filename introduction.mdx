The College Scorecard MCP is a Model Context Protocol server that gives AI assistants direct, structured access to the U.S. Department of Education's official College Scorecard dataset. Whether you're building an AI-powered college search tool or simply asking an AI assistant to help you compare schools, the College Scorecard MCP bridges the gap between natural language and authoritative higher education data — covering costs, outcomes, admissions, programs, and more for thousands of institutions across the United States.

## What Is the College Scorecard MCP?

The College Scorecard MCP wraps the [U.S. Department of Education College Scorecard API](https://collegescorecard.ed.gov/data/documentation/) and exposes it as a set of MCP tools that any compatible AI client can invoke. When you (or your users) ask an AI assistant a question like *"What are the most affordable engineering schools in Texas?"*, the assistant calls the appropriate MCP tool, retrieves live College Scorecard data, and synthesizes a response — all without you ever writing a line of data-fetching code or managing an API key.

<Note>
  You do not need a College Scorecard API key to use this service. The MCP server handles all authentication with the upstream data source on your behalf. See [Authentication](/authentication) for details.
</Note>

## Available MCP Tools

The College Scorecard MCP exposes four tools to AI assistants:

<CardGroup cols={2}>
  <Card title="search_schools" icon="magnifying-glass">
    Search for schools by name, location, size, acceptance rate, cost, or any combination of College Scorecard fields. Returns a paginated list of matching institutions.
  </Card>
  <Card title="get_school" icon="school">
    Retrieve the full College Scorecard profile for a single institution by its ID, including admissions data, costs, outcomes, and programs offered.
  </Card>
  <Card title="compare_schools" icon="code-compare">
    Accept a list of school IDs and return a side-by-side comparison across key metrics: tuition, graduation rates, median earnings, and more.
  </Card>
  <Card title="find_programs" icon="book-open">
    Search for schools that offer specific academic programs using standard CIP (Classification of Instructional Programs) codes, such as Computer Science (11.0701) or Business Administration (52.0201).
  </Card>
</CardGroup>

## How It Works

The College Scorecard MCP sits between your AI client and the College Scorecard data source. Here's the flow at a high level:

1. **Your AI client** (Claude Desktop, Cursor, or any MCP-compatible assistant) connects to the MCP endpoint at `https://box-college-scorecard-mcp.box-athletic-6399.chatgpt.site/api/mcp`.
2. **The MCP server** receives tool calls from the AI, validates arguments, and forwards authenticated requests to the College Scorecard API.
3. **College Scorecard data** is fetched, normalized, and returned to the AI client as structured JSON.
4. **Your AI assistant** interprets the data and responds in natural language.

No credentials flow through the client. No API keys to rotate. No rate-limit tokens to manage on your end.
