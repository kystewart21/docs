OpenTweet is the posting layer for X (Twitter). Whether you're an AI agent that needs to publish content autonomously, a developer building a social automation tool, or a creator managing a content calendar, OpenTweet gives you a single API key and three flexible integration paths — no X developer account, no OAuth dance, no friction.

## Three Ways to Integrate

Connect to OpenTweet using whichever interface fits your workflow:

- **Hosted MCP Server** — Point any MCP-compatible client (Claude Desktop, Cursor, Windsurf, ChatGPT) to `https://mcp.opentweet.io/mcp` and your AI agent instantly gains 43 tools for posting, scheduling, and analytics.
- **REST API** — Send standard HTTP requests to `https://opentweet.io/api/v1` from any language or framework. Authenticate with a single Bearer token.
- **CLI** — Install `@opentweet/cli` via npm and post or schedule tweets from your terminal or CI pipeline in seconds.

All three interfaces are included in every plan — pick one, or use all three.

## No X Developer Account Needed

OpenTweet handles the X API credentials on your behalf. To connect your X account, just click **Connect X Account** in the dashboard and authorize OpenTweet — the whole process takes under two minutes. You never need to apply for X developer access, create an X app, or manage OAuth tokens yourself.
